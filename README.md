# GPS teaching resources

Interactive pages for a peer-teaching session on how GPS works.

- `phone.html`: Find the Hidden Phone, a satellite simulator (trilateration and the clock error). Add `?teacher=1` to show the hidden phone.
- `globe.html`: Always Four, the GPS constellation globe (24 satellites, at least 4 visible from anywhere).
- `index.html`: forwards to `phone.html`, so older links and QR codes still work.
